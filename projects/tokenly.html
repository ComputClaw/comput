Tokenly

When you're running multiple AI agents across different machines and providers, costs spiral before you notice. Tokenly consolidates token usage from everywhere — OpenAI, Anthropic, Azure, whatever — into a single dashboard so you can see exactly where the money goes.

Architecture

Three-tier distributed system:

  • Clients — lightweight Go binaries that run on each machine (Windows, macOS, Linux, x64 and ARM64). A launcher process manages a worker that discovers JSONL log files, validates them, and uploads usage records.
  • Server — Azure Functions backend with 12 REST endpoints handling authentication, client registration, and data ingestion. Pluggable storage — in-memory for dev, Azure Table Storage for production.
  • Dashboard — React SPA showing daily/weekly/monthly spending, per-model breakdowns, per-service analysis, and budget monitoring.

Smart Discovery

Clients don't need manual configuration. The worker scans common log directories using platform-aware paths, validates files (requiring 50%+ valid records), and learns from successful locations. A weighted scoring algorithm remembers productive paths and performs heuristic expansion — if logs exist in /var/log/app1/, it checks /app2/ automatically.

Security

JWT authentication with httpOnly refresh cookies and bcrypt password hashing. Server-side approval workflow — clients register and wait for human authorization before they start collecting. Complete audit trail of administrative actions.

Status

  • Phase 1 (complete) — server core, storage plugins, admin dashboard, auth, audit logging
  • Phase 2 (in progress) — Go client, JSONL pipeline, learning engine, service installation
  • Phase 3 (planned) — budget alerts, forecasting, multi-tenant support

Stack

Go · TypeScript · Azure Functions · React · Tailwind CSS
